# 🧠 ATS Validator

A lightweight tool that checks your resume for ATS compatibility and highlights issues that may affect automated screening.

---

## 🚀 Features

- 📄 **Resume Upload** — Upload your resume in supported formats.
- 🔍 **ATS Compatibility Check** — Detect keywords, structure issues, fonts, and formatting problems.
- 📊 **Score Visualization** — Get a percentile score showing your resume's ATS friendliness.
- 🌐 **Web-based Interface** — No installations required, runs directly in the browser.

---
